# B7 用户操作手册

> **文档目的**：手把手指导每个岗位的员工如何使用YMT OMS。建议每位员工通读本章对应角色部分，并参考截图实际操作一遍。
>
> **建议使用方式**：将本文档拆分为 6 个角色分册分发给员工（业务员 / 采购 / 生产 / 物流 / 内勤跟单 / 审批经理 / 系统管理员）。

---

## 一、使用前准备

### 1.1 浏览器要求

| 浏览器 | 推荐版本 |
|---|---|
| Chrome | 最新版（强烈推荐） |
| Microsoft Edge | 最新版 |
| Firefox | 最新版 |
| Safari | 最新版（仅 Mac 用户） |

> ⚠️ **不支持 IE 浏览器**。请确保浏览器自动更新已开启。

**显示器分辨率**：建议 1920×1080，最低 1280×800。

### 1.2 账号获取

**方式一：管理员开通（推荐）**

1. 由系统管理员直接创建账号
2. 管理员告知您的**登录手机号 / 姓名 + 初始密码**
3. 首次登录后立即修改密码

**方式二：自助注册**

1. 访问系统登录页，点击"立即注册"
2. 填写姓名、手机号、密码、选择角色
3. 提交后等待**管理员审核**（一般 1 小时内）
4. 审核通过后可登录

### 1.3 首次登录与改密

1. 输入手机号 / 姓名 + 密码 → 登录
2. 进入系统后，点击右上角头像 → "修改密码"
3. 输入旧密码 + 新密码 + 确认密码
4. 提交后**所有设备上的旧登录将失效**，需用新密码重新登录

> **密码要求**：6 位以上，含字母与数字。

## 二、登录与首页

### 2.1 登录页

- 默认在浏览器输入 `https://<公司域名>`
- 输入账号密码 → 点击"登录"
- 勾选"记住我"可保持登录状态 24 小时
- 忘记密码：点击"忘记密码" → 提交申请 → 联系管理员

### 2.2 个人工作台

登录后默认进入**个人工作台**：

- **顶部 KPI 卡片**：根据您的角色显示不同指标
  - 业务员：我的订单数、待审批数、本月销售额
  - 采购：待采购订单数、缺料预警数
  - 生产：待生产订单数
  - 物流：待发货订单数
  - 经理 / 内勤：全公司订单数、待审批数（含发货审批）
- **待办事项**：需要您处理的任务清单
- **最近动态**：最近 24 小时的关键状态变化

### 2.3 顶部导航与角色切换

顶部菜单条根据您的角色显示对应 Tab：

```
工作台 | 业务员 | 采购 | 生产 | 物流 | 审批管理 | 用户管理 | 数据看板
```

- 业务员只看到：工作台、业务员、数据看板
- 采购看到：工作台、采购、数据看板
- 经理看到全部（视子角色而定）
- 右上角**头像 → 退出登录** 安全离开

## 三、业务员操作指南

### 3.1 新建订单

**步骤**：

1. 顶部点击 **「业务员」** Tab → 「订单管理」子页面
2. 点击右上角 **「新建订单」** 按钮
3. 在弹窗内填写：
   - **客户**：下拉选择（可输入关键字搜索）；不存在时点击"新建客户"
   - **合同参考号**（可选）：客户的 PO 号
   - **交货日期**：必填
   - **业务员**：默认本人，经理可指派他人
   - **备注**：自由文本
4. 在「产品明细」表格逐行添加：
   - 产品名称、规格、单位、数量、单价
   - 小计自动计算
5. 检查无误后点击 **「保存为草稿」** 或 **「保存并提交审批」**

> 💡 **小技巧**：草稿订单可反复修改，提交审批后再修改需要先撤回。

### 3.2 Excel 导入订单

适用于客户给的是 Excel 订单表（含合同信息 + 产品明细）。

**步骤**：

1. 点击 **「新建订单」** → 切换到 **「Excel 导入」** Tab
2. 拖入或选择 `.xlsx` / `.xls` 文件（≤ 10 MB）
3. 系统**自动解析**：
   - 客户名称（智能识别中英文）
   - 合同号、订单日期、交货日期
   - 全部产品明细行
4. 在预览界面**检查**解析结果：
   - 客户匹配错？手动从下拉框选择正确客户
   - 产品明细错？直接在表格中编辑
   - 缺字段？红色提示，需补齐
5. 点击 **「确认导入」** → 系统自动生成订单（草稿态）
6. 回到订单列表，可继续编辑或提交审批

> ⚠️ **常见问题**：
> - 客户名称识别为空 → 手动选择，并把客户名加到客户档案
> - 客户名称识别为乱码 → 已自动屏蔽，需手动输入
> - 日期识别错误 → 在预览界面手动修改

### 3.3 客户管理

**新建客户**：

1. 顶部 **「业务员」 → 客户管理」** → 「新建客户」
2. 填写：客户名称（必填）、联系人、联系方式、地址、备注
3. 保存即可

**查看客户详情**：

1. 客户列表点击客户名 → 进入客户详情页
2. 三张卡片展示：
   - **基本信息**：联系方式、地址、备注
   - **沟通记录**：所有与该客户的电话 / 微信 / 见面记录
   - **订单历史**：该客户所有订单（含状态、金额）
3. 右侧时间线展示完整往来记录

**新增沟通记录**：

1. 客户详情页 → 沟通记录卡片 → 「新增」
2. 选择沟通方式（电话 / 微信 / 见面 / 邮件）
3. 输入内容 + 日期 → 保存

> 💡 **离职交接保障**：所有沟通记录归属公司，您离职后接替的同事可无缝接续。

### 3.4 订单详情查看与修改

**查看订单详情**：

1. 订单列表点击合同号 → 右侧弹出宽抽屉（920 px）
2. 上半部分：合同信息 + 状态进度条
3. 中部：产品明细表格
4. 下部：审批日志时间线（每次状态变更都有记录）

**修改订单**（仅 draft / 退回修改 状态可改）：

1. 抽屉右上角 **「编辑」** 按钮
2. 修改交期 / 备注 / 明细 → 保存
3. 系统自动校验合理性

**删除订单**（仅 draft 状态可删）：

1. 抽屉右上角 **「删除」** 按钮 → 确认对话框 → 删除
2. 已提交审批的订单需先撤回或经审批驳回后才能删除

### 3.5 提交审批

1. 草稿订单 → 点击 **「提交审批」**
2. 订单状态变为「待审批」
3. 系统自动**通知审批经理**
4. 等待审批结果：
   - **通过**：订单转入采购环节
   - **退回修改**：附带原因，您修改后再提交
   - **驳回**：订单关闭

> 💡 在工作台的"待办"中可看到所有"退回修改"的订单，及时处理。

## 四、采购操作指南

### 4.1 采购任务列表

1. 顶部点击 **「采购」** Tab
2. 默认显示「采购任务」子页面，列出所有已审批待采购订单
3. 列表字段：合同号、客户、产品摘要、款数、业务员、交期、操作
4. 可按合同号 / 客户 / 业务员筛选

### 4.2 物料录入与编辑

**展开物料子表**：

1. 点击订单左侧 **▶ 三角箭头** → 展开物料子表
2. 子表内按产品明细分组显示物料

**新增物料**：

1. 子表内点击 **「+ 新增物料」** 按钮
2. 弹窗填写：
   - 关联订单明细（必选）
   - 物料名称
   - 规格
   - 单位
   - 需求数量
3. 点击保存

**编辑物料**：

1. 子表内点击物料行 **「编辑」** 按钮
2. 弹窗内修改名称 / 规格 / 单位 / 数量
3. 关联的订单明细不可改（防止数据错乱）

**删除物料**：

1. 子表内点击 **「删除」** → 确认对话框
2. 已"已备齐"的物料不可删除（先切回采购中再删）

### 4.3 库存台账

1. 顶部 **「采购」 → 库存台账」** 子页面
2. 显示全部物料库存：物料名 / 规格 / 单位 / 当前数量 / 状态
3. 状态柱：
   - **正常**（黑色）：库存充足
   - **偏低**（橙色）：库存低于阈值
   - **—**（灰色）：未设置阈值
4. 可按名称 / 规格搜索

**库存调整**：

1. 点击物料行 **「调整」** 按钮
2. 输入数量变化（正数入库 / 负数出库）+ 原因
3. 保存后实时更新

### 4.4 标记备齐

1. 在采购任务列表的物料子表中找到该物料
2. 右侧 **「备齐开关」** —— 拨到右侧（绿色）= 已备齐
3. 系统自动记录操作时间
4. 当某订单**所有物料都备齐**后，订单自动流转至生产环节

> 💡 **常见误操作**：勿在物料未实际到货前点"备齐"，否则生产端会浪费时间在没有物料的订单上。

## 五、生产操作指南

### 5.1 生产任务列表

1. 顶部点击 **「生产」** Tab
2. 列表显示所有"采购备齐、待生产"的订单
3. 列表字段：合同号、客户、产品摘要、款数、业务员、交期、操作

**查看详情**：

1. 点击合同号 → 弹出订单详情抽屉
2. 包含完整产品明细与物料清单

### 5.2 完成生产

1. 订单生产完成后，在生产任务列表点击订单行 **「完成生产」** 按钮
2. 弹窗确认 → 可选填备注
3. 提交后订单转入"待发货"状态
4. 物流端会同步看到该订单

> ⚠️ "完成生产"不可逆，请在产品**实际完成并完成质检**后再点击。

## 六、物流操作指南

### 6.1 待发货列表

1. 顶部点击 **「物流」** Tab → 「待发货」子页面
2. 列表字段：合同号、客户、产品摘要、款数、业务员、总数量、交期、操作

### 6.2 录入快递单号

1. 待发货列表点击订单行 **「发货」** 按钮
2. 弹窗内填写：
   - **物流公司**（下拉：顺丰 / 京东 / EMS / 德邦 / 其他）
   - **快递单号**
   - 备注（可选）
3. 点击 **「确认发货」**

### 6.3 提交发货审批

- 上一步点击"确认发货"后，订单**自动**进入"待发货审批"
- 系统提示"已提交发货审批"
- 内勤跟单 / 系统管理员会在审批管理界面看到该订单

**查看已发货**：

1. 切换到 **「已发货」** 子页面
2. 显示所有已发货 + 待审批发货订单
3. 列表含"审批状态"列（待审批 / 已通过 / 已驳回）

**被驳回的处理**：

1. 已发货页面看到状态为"已驳回"的订单
2. 切回"待发货"页面，找到该订单
3. 重新点击"发货"，修正快递单号后再次提交

## 七、内勤跟单操作指南

### 7.1 发货审批

1. 顶部 **「审批管理」** Tab → 「待发货审批」子页面
2. 列表显示所有物流提交的发货申请
3. 列表字段：合同号、客户、产品摘要、款数、业务员、总数量、总价、交期、**快递单号**、操作

**审批步骤**：

1. 检查快递单号是否合法、是否与订单匹配
2. 点击 **「通过」** → 订单状态变为"已发货"，对客户可见
3. 或点击 **「驳回」** → 弹窗填写原因 → 退回物流重新提交

### 7.2 用户列表查看

内勤跟单**只读**访问用户列表，便于核对人员信息：

1. 顶部 **「用户管理」** Tab
2. 全部用户列表可见（姓名 / 手机号 / 角色 / 状态）
3. 可使用筛选器搜索
4. 无修改 / 删除权限（如需操作，联系系统管理员）

## 八、审批经理操作指南

### 8.1 订单审批

1. 顶部 **「审批管理」** Tab → 「订单审批」子页面
2. 列表显示所有业务员提交的待审批订单
3. 列表字段：合同号、客户、产品摘要、款数、业务员、总数量、总价、交期、操作

**审批操作**：

1. 点击合同号 → 弹出订单详情抽屉
2. 检查：
   - 客户是否准确
   - 产品规格、数量、单价是否合理
   - 交期是否可行
3. 三选一操作：
   - **通过**：订单转入采购环节
   - **退回修改**：弹窗填写原因 → 业务员修改后重新提交
   - **驳回**：弹窗填写原因 → 订单关闭，不可再用

### 8.2 退回修改 vs 驳回的区别

| 操作 | 后续路径 | 适用场景 |
|---|---|---|
| **退回修改** | 业务员修改后可再次提交 | 信息错误、小调整 |
| **驳回** | 订单关闭，不可恢复 | 客户取消、不合规 |

### 8.3 历史记录

1. 切换到 **「历史记录」** 子页面
2. 显示所有已审批订单（通过 / 退回 / 驳回）
3. 列出审批结果、审批人、审批时间、审批原因
4. 可按时间范围 / 客户 / 业务员筛选

## 九、系统管理员操作指南

### 9.1 用户管理 — 注册审核

1. 顶部 **「用户管理」** Tab → 「待审核用户」子页面
2. 列表显示所有自助注册待审核的账号
3. 检查信息后点击：
   - **通过** → 账号激活
   - **驳回** → 弹窗填写原因

### 9.2 用户管理 — 全部用户

1. 切换到 **「全部用户」** 子页面
2. 列表字段：姓名、手机号、角色、子角色、启用状态、操作
3. 筛选器：角色 / 子角色 / 状态 / 关键字

**操作菜单**：

| 操作 | 说明 |
|---|---|
| **编辑** | 修改姓名、手机号、备注 |
| **改角色** | 切换业务员 / 采购 / 生产 / 物流 / 经理；经理需选子角色 |
| **重置密码** | 设置一个新密码，用户用新密码登录 |
| **启用 / 禁用** | 即时生效，用户旧 token 立即失效 |
| **删除** | 软删除（保留历史数据） |

### 9.3 角色与权限分配

**角色矩阵**（V1.0）：

| 角色 | 默认子角色 | 主要权限 |
|---|---|---|
| 业务员（sales） | — | 订单 + 客户 |
| 采购（purchasing） | — | 物料 + 库存 |
| 生产（production） | — | 生产任务 |
| 物流（logistics） | — | 发货 |
| 经理（manager） | 选择以下之一 | 见下 |
| ┗ 审批经理（approval_manager） | — | 订单审批 |
| ┗ 内勤跟单（clerk） | — | 发货审批 + 只读用户列表 |
| ┗ 系统管理员（system_admin） | — | 用户管理 + 全部审批权 |
| 超级管理员（admin） | — | 全部权限（极少授予） |

> 💡 **修改角色后**：用户当前登录会立即失效，需重新登录。

### 9.4 数据看板访问

系统管理员默认拥有数据看板访问权（顶部「数据看板」Tab）。

## 十、仪表盘（数据看板）使用说明

进入路径：顶部 **「数据看板」** Tab。

**看板组成**：

1. **顶部 KPI 卡片**（4 个）
   - 总订单数（含同比）
   - 总销售额（含同比）
   - 客户数
   - 待审批订单数

2. **月度销售趋势**
   - 折线图：最近 12 个月销售额
   - 鼠标悬停查看具体数值

3. **风险预警订单**
   - 红色：已逾期未发货
   - 黄色：3 天内交期、未完成
   - 点击订单可跳转至详情

4. **最新订单列表**
   - 最近 10 单实时刷新

5. **客户地理分布**
   - 矢量地图标记客户所在地
   - 点的大小代表订单金额规模

**数据权限**：

- 业务员：仅本人客户与订单
- 采购 / 生产 / 物流：相关环节数据
- 经理 / 管理员：全公司视图

## 十一、常见问题 FAQ

### Q1：登录提示"用户名或密码错误"

- 检查输入是否准确（注意大小写）
- 联系管理员确认账号是否被禁用
- 必要时请求管理员重置密码

### Q2：登录后看不到某个 Tab

- 该 Tab 对您的角色不可见，属正常现象
- 如需访问，联系系统管理员调整角色

### Q3：订单提交审批后无法修改

- 提交后订单状态变为"待审批"，需经理"退回修改"或"驳回"后才能改
- 紧急情况联系经理

### Q4：Excel 导入失败

- 检查文件格式：必须是 `.xlsx` 或 `.xls`，不支持 `.csv`
- 文件大小：≤ 10 MB
- 内容要求：表格内至少有产品名称列、数量列
- 如客户名识别为空：手动从下拉框选择

### Q5：客户在订单列表搜不到

- 联系业务员或系统管理员确认客户档案是否已建立
- 客户档案在「业务员 → 客户管理」中维护

### Q6：物料备齐后误操作

- 在物料子表找到该物料，将"备齐开关"拨回左侧（采购中）
- 不会影响订单整体状态（除非订单已流转至生产）

### Q7：发货被驳回怎么办

- 在物流「已发货」列表查看驳回原因
- 切回「待发货」重新填写正确单号 → 再次提交

### Q8：忘记密码

- 登录页点击"忘记密码"→ 提交申请
- 联系系统管理员通过"用户管理 → 重置密码"操作

### Q9：登录后突然被踢出

- 您的账号被管理员禁用 / 角色变更 / 改密
- 联系管理员确认情况

### Q10：浏览器卡顿 / 数据不刷新

- 按 `Ctrl + F5`（Windows）或 `Cmd + Shift + R`（Mac）强制刷新
- 清理浏览器缓存
- 必要时关闭再重新打开浏览器
